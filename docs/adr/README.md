# Architecture Decision Records (ADR)

Use ADRs to capture important technical decisions that shape the project.

## Naming
- `NNNN-short-title.md`
- Example: `0001-dialogue-action-registry.md`

## When To Write One
- New cross-cutting architectural pattern
- Significant change in core flow or persistence strategy
- Tradeoff decision with long-term impact

## Process
1. Copy `0000-template.md`
2. Fill context, decision, consequences
3. Link impacted folders/modules
4. Keep status updated (`proposed`, `accepted`, `superseded`)
