# Scripts Guide

`scripts/` holds maintenance, validation, and simulation scripts.

## Rules
- Scripts should be deterministic when possible.
- Script output should clearly state pass/fail conditions.
- Keep script usage documented at the top of each file.

## Typical Categories
- Data validation
- Balance simulation
- Content transformation utilities

## Documentation Requirement
When adding a script, document:
- purpose
- inputs
- outputs
- safe usage notes
